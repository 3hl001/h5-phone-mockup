# H5 长图替换说明

请将 7 张 H5 长图放在本文件夹中，并使用以下文件名：

- `home.png`：首页
- `pilot.png`：飞行学员组合包
- `civil-defense.png`：民防部队组合包
- `bounty-hunter.png`：赏金猎人组合包
- `deep-space.png`：深空探索组合包
- `pioneer.png`：开拓者赞助组合包
- `cart.png`：飞行学员购物车

当前图片已经接入。后续替换时建议使用相同宽度，图片高度可以不同，网页会按手机屏幕宽度自动缩放。

如果图片格式或文件名不同，请修改上一级目录中 `script.js` 文件顶部的 `PAGES` 配置。
