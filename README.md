# H5 手机样机展示

这是一个无需安装依赖的 HTML、CSS、JavaScript 项目。

手机内容区使用 `423 × 918 px` 画幅，由 `141 × 306 px` 等比放大，保持 iPhone 17 纵向比例并提高展示清晰度。
网页中通过外层容器将手机等比显示为约 60%，内部画幅与菜单对齐坐标保持不变。
网页背景使用 `assets/background.webp`，图片层透明度为 70%。

## 替换长图

打开 `assets/README.md`，按照其中的文件名放入 7 张长图：1 张首页、5 张购票页面和 1 张购物车页面。

## 本地预览

最简单的方式是直接双击 `index.html`。

如果电脑已经安装 VS Code，也可以使用 Live Server 扩展打开 `index.html`。使用本地服务器预览时，页面地址通常类似 `http://127.0.0.1:5500`。

## 页面选择

手机下方提供 7 个页面按钮，可以直接切换首页、5 个购票页面和购物车页面。页面配置位于 `script.js` 顶部的 `PAGES`。

首页图片中的四个底部菜单均带悬浮和按压反馈。第二个购物车按钮会切换到购物车页面，其余三个按钮不跳转。

## 播放规则

- 单页从顶部缓慢滚动到底部
- 到底停留 1.8 秒
- 平滑返回顶部
- 返回顶部后循环播放当前页面
- 鼠标移入手机时暂停，移出后继续
- 手机内部始终支持鼠标滚轮与触控手动浏览
- 系统开启减少动态效果时，自动播放会停止
